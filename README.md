# Xingbo Li's Academic Homepage

Personal academic homepage of **Xingbo Li (李兴博)**, a master's student at Wuhan Textile University.

- Site: <https://xingboli.github.io>
- Email: xingbo.li@hotmail.com

Built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll template and hosted on GitHub Pages.

## How to update

1. Edit content under `_pages/`, `_bibliography/`, `_data/`, or `_config.yml`.
2. Commit and push to `main`; GitHub Actions rebuilds and deploys automatically.

## Local preview (optional)

Requires Docker. From the repo root:

```bash
docker compose up
```

Then open <http://localhost:8080>.
